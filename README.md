A GTA 6 clipper for make.fun's gta6-clipper-01 bounty: it hands the gate the address of the public YouTube Short — the getaway chase from GTA 6 Trailer 2 (airboat, jet ski, motorcycle under a plane), cut vertical with make.fun's pitch on screen — by copying VIDEO.json to /output.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
